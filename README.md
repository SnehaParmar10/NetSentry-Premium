..# 🛰️ NetSentry | Network Traffic Visualizer

A sophisticated network visualization tool that uses Canvas animations to represent data flow, node connectivity, and system health.

## ✨ Features
- **Node-Link Visualization**: Dynamic Canvas-based particles connected by logic-driven lines.
- **Real-Time Log HUD**: Fictional status logger showing system events (Auth, Encryption, Threats).
- **Cyber-Blue Aesthetic**: Neon styles designed for "Command Center" environments.
- **Performance Optimized**: Built using efficient animation frames for smooth rendering.

## 🛠️ Tech Stack
- **Core**: HTML5 Canvas API, JavaScript.
- **Design**: Space Mono Typography and Neon-Bordered HUDs.

## 🧠 Why I built this?
Networking is the backbone of the internet. I built NetSentry to visualize how nodes interact in a distributed system, focusing on the beauty of connectivity and data transfer.
